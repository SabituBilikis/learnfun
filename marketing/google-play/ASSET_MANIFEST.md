# Learn Fun Google Play Asset Manifest

All assets are English-language PNGs for the Learn Fun Google Play listing. The screenshots are genuine captures of the current app UI with its temporary browser install prompt hidden only during capture.

## Store Graphics

| File | Dimensions | Alt text | Play Console placement |
| --- | --- | --- | --- |
| `icon/learn-fun-icon-512.png` | 512 × 512 | Learn Fun icon with an open book, star, rainbow and colourful learning shapes | Main store listing app icon |
| `feature-graphic/learn-fun-feature-graphic-1024x500.png` | 1024 × 500 | Learn Fun interactive learning for ages 1–5 with real app screens | Feature graphic |

The icon master is `icon/learn-fun-icon-master.svg`. It is rendered to the 512 × 512 transparent PNG above and to the Android/PWA icon variants by `generate-icons.js`.

## Upload Notes

- Upload the six screenshots in the listed order for each device class. Each tablet class has six images, exceeding Google Play's four-image tablet minimum.
- Use the feature graphic as supplied; it has no rank, badge, discount, third-party mark, device mockup, or unsupported capability claim.
- The screenshot captions describe existing functionality only: learning choices, letters, number activities, shapes, rewards, and parent controls.
